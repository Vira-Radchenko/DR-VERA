# DR. VERA — сайт дерматолога-косметолога

Демонстраційний багатосторінковий сайт (макет) косметологічних послуг.
Дизайн і верстка: Віра Радченко.

## Сторінки

| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `services.html` | Послуги (пошук, фільтри, «Показати ще») |
| `prices.html` | Ціни (прайс-таблиці, пошук, фільтри) |
| `about.html` | Про мене |
| `results.html` | Результати (слайдер «до / після», фільтр кейсів) |
| `contacts.html` | Контакти |

## Що працює

- Адаптивне меню (бургер на мобільному), липка шапка
- Онлайн-запис: календар, вибір часу, форма з перевіркою полів (вікно відкривається з кожної кнопки «Записатися»)
- Пошук і фільтри послуг, цін та кейсів; посилання на кшталт `services.html?concern=сухість` одразу фільтрують список
- Вікна «Детальніше», акордеон FAQ, слайдер відгуків, порівняння «до / після»
- Демо-чат підтримки з швидкими відповідями
- Форми зворотного зв’язку з перевіркою та повідомленням про відправку

Сайт є демо: заявки нікуди не надсилаються.

## Структура

```
index.html, services.html, prices.html, about.html, results.html, contacts.html
css/style.css   — усі стилі (змінні кольорів на початку файлу)
js/main.js      — інтерактив
img/            — зображення
```

## Зображення

Зараз у папці `img/` лежать фрагменти, вирізані з макетів. Щоб фото були чіткими,
замініть їх оригінальними зображеннями **з тими самими назвами файлів** (наприклад, `hero-home.jpg`, `about-portrait.jpg`).

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub і завантажте в нього всі файли та папки проєкту.
2. Відкрийте **Settings → Pages**.
3. У розділі **Branch** оберіть `main` і папку `/ (root)`, натисніть **Save**.
4. За 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
